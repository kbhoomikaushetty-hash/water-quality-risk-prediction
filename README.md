# Water Quality Risk Prediction System

AI-powered Water Quality Risk Prediction and Treatment Recommendation System using Machine Learning.

## Features
- Manual Water Quality Prediction
- Dataset-Based Prediction
- State-wise Water Body Selection
- WQRI Calculation
- Treatment Recommendations
- Water Usage Recommendations

## Technologies
- Python
- Streamlit
- Pandas
- Scikit-Learn
- Random Forest
- SMOTE

## Dataset
National Water Monitoring Programme (2020–2024)
